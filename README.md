# Greeting App
Description

This is a simple web application that asks the user for their name and displays a personalized greeting along with a random positive message. Examples of messages include “Have a great day!”, “Keep shining today!”, and “You are doing amazing!”.

This project was created as part of a school assignment to practice cloud hosting using GitHub Pages.

How to Use:
• Open the live GitHub Pages link below.
• Type your name into the input box.
• Click the Greet Me button.
• See your personalized greeting and a random positive message!

Features:

Interactive greeting based on user input.
Randomly displays a positive message each time.
